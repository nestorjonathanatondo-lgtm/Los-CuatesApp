# Los Cuates - Tamales Hoja Plátano

Aplicación de pedidos para Los Cuates Tamales (Saltillo).

## Qué puedes hacer desde la app

- Ver el menú y armar tu pedido
- Calcular envío por distancia
- Generar ticket con QR y enviarlo por WhatsApp o correo
- Pagar por transferencia

## Administración

Toca el logo del pie 3 veces y mantén presionado para abrir la administración.

Desde ahí puedes cambiar:
- Productos y extras (nombre, descripción, precio, costo, stock e imagen)
- Textos y colores
- Logos
- Promociones
- Datos de pago y contacto
- Inventario, lotes, gastos y corte del día
- Horario y estado abierto/cerrado

Los cambios se guardan automáticamente.

## Desarrollo

```bash
npm run dev
npm run build
```
